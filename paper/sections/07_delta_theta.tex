\section{System-Prompt Strictness and \texorpdfstring{$\theta$}{Theta}}
\label{sec:deltatheta}

% The engineering arc: use the frozen instrument to measure interventions.
Part~1 produced a fixed, calibrated instrument. I now use it to ask an
engineering question. When a system-prompt intervention appears to make a
model better at compliance, what exactly improved? Because the bank is
Rasch-calibrated, I can read each configuration's ability $\theta$ on a
common scale and compare interventions as differences $\Delta\theta$.

\subsection{Setup}
I hold the bank fixed at the $1{,}284$ frozen items and score nine
subject configurations. These are three models
(\texttt{llama-3.3-70b-versatile}, \texttt{openai/gpt-oss-20b}, and
\texttt{llama-3.1-8b-instant}) at a single temperature ($t = 0.4$) under
three system-prompt strictness levels (\texttt{none}, \texttt{neutral},
and \texttt{strict}). Restricting the bank to the healthy subset shifts
the baseline's ability, so I re-anchor inside the analysis in order to
keep the absolute $\theta$ values honest. The $\Delta\theta$ comparisons
within a model are invariant to this shift.

\subsection{The dual-judge decomposition}
The strict judge requires section-level citations. So a measured prompt
effect can mean two very different things. Either the prompt taught the
model to \emph{cite}, which is a format unlock, or it taught the model to
\emph{reason} better about compliance. To separate the two, I re-grade
the same saved responses with the lenient judge, which scores the
conclusion and reasoning but requires no citation, and define per model

\begin{align}
\text{reasoning gain} &= \Delta\theta_{\text{lenient}}
  \quad(\text{none}\!\to\!\text{strict}),\\
\text{format unlock}  &= \Delta\theta_{\text{strict}}
  - \Delta\theta_{\text{lenient}}.
\end{align}

The re-grade is offline, because it reuses the response text already
logged in Phase~1. So the decomposition adds judge calls but no new
solver calls.

\subsection{Results}
Under the strict judge, system-prompt strictness moves all three models,
and it moves the 70b furthest (Table~\ref{tab:deltatheta},
Figure~\ref{fig:deltatheta}). Under the lenient judge, however, the
effect flattens for everything except the 70b. For
\texttt{gpt-oss-20b} and the 8b the lenient $\Delta\theta$ is essentially
zero (Figure~\ref{fig:decompose}). The reading I take from this is that
\textbf{system-prompt strictness primarily teaches citation format rather
than compliance reasoning}. Only the 70b shows a non-trivial reasoning
gain, of about $+2.5$ logits, on top of the format-unlock component.
